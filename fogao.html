Nova Interface do Fogão

O fogão conta com:

  • Bocas em formato assimétrico facilitando a associação entre bocas e controles.
  • Grandes botões táteis com leds RGB e numerais indicativos a fim de facilitar o uso por pessoas com deficiências visuais e motoras.
  • Sistema de controle por voz, permitindo os usuários controlarem acendimento e temperatura das bocas do fogão por meio de comandos de voz.
  • Feedbacks sonoros para alterações de estado, garantindo feedbacks claros para todos os usuários.
  • Ajuste de altura, permitindo que o fogão seja elevado ou rebaixado conforme a necessidade do usuário.

As cores dos botões foram escolhidas para serem facilmente distinguíveis, com opções de personalização para daltonismo. Tais cores também indicam o nível de calor, proporcionando uma experiência intuitiva.

Necessidades atendidas

Este fogão foi projetado para atender necessidades de pessoas em diversas condições, entre elas: mobilidade reduzida, deficiências físicas, nanismo, deficiências visuais e auditivas, analfabetismo e até mesmo usuários infantis.

Os botões em formato personalizado, leds indicativos e o sistema de controle por voz auxiliam a usabilidade para pessoas com deficiências visuais, analfabetos e crianças.

Além disso, os botões táteis e o ajuste de altura beneficiam usuários com mobilidade reduzida, cadeirantes, e pessoas de baixa estatura.

Manual de Utilização do Fogão Acessível

1. Acendendo uma Boca do Fogão

Para acender uma boca do fogão, siga os passos abaixo:

  1. Identifique a boca que deseja acender pelo formato, numeral ou cor do led correspondente.
  2. Pressione o botão correspondente à boca desejada. Você ouvirá um som de clique indicando que o botão foi pressionado.
  3. O led do botão acenderá na cor respectiva, indicando que a boca está acesa.

Alternativamente, você pode acender a boca do fogão usando comandos de voz. Para isso, siga os passos abaixo:

  1. Diga o comando "Acender boca [número]" para a boca desejada ou "Acender boca [cor]" para a boca com a cor correspondente.
  2. O led correspondente à boca acenderá e um som de clique será emitido, indicando que a boca está acesa.

2. Ajustando a Temperatura

Para ajustar a temperatura de uma boca do fogão, siga os passos abaixo:

  1. Pressione por três segundos o botão da boca que deseja ajustar.
  2. O led do botão começará a piscar, indicando que está no modo de ajuste de temperatura.
  3. Pressione o botão repetidamente para alternar entre as temperaturas baixa, média e alta. O led mudará de intensidade de acordo com a temperatura selecionada.
  4. Solte o botão para confirmar a temperatura selecionada. Um som de confirmação será emitido.

Alternativamente, você pode ajustar a temperatura usando comandos de voz. Para isso, siga os passos abaixo:

  1. Diga o comando "Ajustar boca [número] para [baixa/média/alta]" ou "Ajustar boca [cor] para [baixa/média/alta]".
  2. O led correspondente à boca mudará de intensidade de acordo com a temperatura selecionada e um som de confirmação será emitido.

3. Desligando uma Boca do Fogão

Para desligar uma boca do fogão, siga os passos abaixo:

  1. Identifique a boca que deseja desligar pelo formato, numeral ou cor do led correspondente.
  2. Pressione o botão correspondente à boca desejada. Você ouvirá um som de clique indicando que o botão foi pressionado.
  3. O led do botão ficará em luz fraca, indicando que a boca está desligada.

Alternativamente, você pode desligar a boca do fogão usando comandos de voz. Para isso, siga os passos abaixo:

  1. Diga o comando "Desligar boca [número]" para a boca desejada ou "Desligar boca [cor]" para a boca com a cor correspondente.
  2. O led correspondente à boca ficará em luz fraca e um som de clique será emitido, indicando que a boca está desligada.
