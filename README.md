# Atividade 1 — Desenvolvimento para Internet I

Atividade 1 da disciplina **Desenvolvimento para Internet I** do curso de Pós-Graduação em Desenvolvimento de Sistemas WEB e Aplicativos Móveis — IFSP Capivari.

## Enunciado

Criar um site estático, utilizando apenas HTML e CSS inline, com o propósito de apresentar uma nova interface acessível para um fogão, considerando diferentes tipos de deficiência e necessidades específicas. O foco está na usabilidade, inclusão e empatia no design.

## Stack

- HTML5
- CSS inline

## Como executar

Abra o arquivo `fogao.html` diretamente no navegador. Não há dependências nem etapa de build.
